# B1 日报图版：排版规范

排版与内容纪律**与市场日报完全一致**，以
`.claude/skills/qk-stock-market-daily/references/image_report_format.md` 为准：

- 留空行（`nl2br` 会把单换行粘成一块）
- **不用横向分割线**（不写 `---`）
- 表格 ≤4 列
- 涨跌用 `.up` / `.down`（**红涨绿跌**），不是 `.positive` / `.negative`
- 无 emoji
- 每章 `>` 收尾
- **不引用规则出处**（不写「《某某》说」）

本文**只讲 B1 特有的内容取舍与结构**，不重复上面那几条。

改动共用规则时改那一份，别在这里抄第二遍——两份规则各自漂移是这类文档最常见的死法。

## 核心：图版要砍掉两段

B1 存档（`b1_results/YYYY-MM-DD.md`）里有两类内容**是给机器用的，不是给人读的**，
图版必须砍掉：

| 段落 | 为什么砍 |
|---|---|
| `股票列表：301060 300314 …` | 给行情软件粘贴用的。图里根本没法复制，长串数字还占版面 |
| `## 完整指标（回测对齐用，CSV）` 整段 | 给回测脚本读的原始数据，40-80 行。图里纯噪声 |

**存档 md 保留这两段**（那是可回溯的记录），只砍图版。所以图版是**重写**，
不是把 md 改两行了事。

## 结构

```
# B1 买点分析　2026-09-15

**命中 52 只 · 第一梯队 7 只 · 空头区间，命中仅作记录**

---

## 一、市场闸门

（活跃市值 + 指数，与市场日报同款两行小表）

---

## 二、第一梯队 · 优秀范本

（表格：股票 / 归类 / J值 / 顶部无量 / 末日缩量 / 区间位置）

---

## 三、第二梯队 · 合格可试错

## 四、第三梯队 · 勉强、需等待

## 五、完美四 · 激进试错

## 六、指数成分（沪深300 / 中证500）

## 七、需人工确认
```

`---` 分隔每个 `##`。序号用中文数字。

## B1 特有的三条

### 1. 梯队列表用项目符号，不用代码块

存档 md 里梯队是 ``` 围起来的等宽竖排（为了复制时对齐）。图版改成普通列表：

```markdown
- **002612 朗姿股份** — 红肥绿瘦最强（2.4/2.87），缩量到位
- **605339 南侨食品** — 量比 2.66，回调至 0.20
```

**成因**：代码块在深色主题下是等宽字体，中文会显得松散突兀；而且图里不能复制，
保对齐没有意义。缩进与空白在图片里是浪费。

### 2. 第一梯队那张表最多 5 列

存档 md 有 7 列（股票/归类/J值/顶部无量/末日缩量/区间位置/亮点）。图版只放得下 5 列。

砍「亮点」并入名称行，或砍「归类」。**优先级：股票、J值、顶部无量、末日缩量、区间位置**——
这五个是量能链的核心读数，其余可在名称后用小字补。

### 3. 章节顺序：闸门必须在最前

与市场日报同理，且 B1 尤其需要——**B1 只回答「哪只票形态好」，闸门回答「现在该不该买」**。
空头区间下命中再多也不构成买入理由。

技能步骤 0 已经跑了闸门，图版把它放在第一节。

## 空头区间的呈现纪律

`SKILL.md` 的纪律写的是「空头区间下的命中一律按**记录**而非**可买**呈现」。图版要贯彻：

- 副标题里直接写「空头区间，命中仅作记录」
- 每个梯队章节的 `>` 收尾块里重复一次，不要只在开头说
- **不要**出现「可买入」「建议关注」这类措辞

**成因**：图版是独立传播的（可能被单独转发或隔几天再看），开头那句提示未必跟着走。
每章重复一次是必要的冗余。

## 写完自检

1. **没有 `股票列表：` 行**，**没有 CSV 段**
2. 梯队列表是项目符号不是代码块
3. 第一梯队表格 ≤5 列
4. 闸门在最前
5. 共用规则按市场日报那份自检：空行、**无 `---`**、涨跌用 `.up`/`.down`、无 emoji、
   每章 `>`、**无规则出处引用**
