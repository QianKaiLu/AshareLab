# 市场日报：两个版本，两份规范

市场日报出**两份内容不同**的产物，不要互相套用：

| | 文字版 | 图片版 |
|---|---|---|
| 路径 | `market_reports/YYYY-MM-DD.md` | `market_reports/YYYY-MM-DD-image.md` + `.png` |
| 内容 | **完整数据 + 完整推理链** | **文字精炼 + 图表** |
| 图表 | 不带（md 源码阅读，图反而碍事） | 必带（折线图 / K 线图） |
| 用途 | 留档、细读、回查 | 分享、快速阅读 |

**为什么必须重写而不是截取**：`market/analyze.py:render()` 那种逐行拼接的紧凑文本，
配合渲染器的 `nl2br`，相邻两行会被粘进同一个 `<p>`，成一块没有呼吸感的文字墙。
实测：

```
输入：  活跃市值 166,792（09-15）
        走势：09-14 -1.42　09-15 -1.83

输出：  <p>活跃市值 166,792（09-15）<br />走势：09-14 -1.42　09-15 -1.83</p>
```

本文规定的是**图片版**；文字版按「完整、可细读」自由组织，无排版约束。

## 版面约束（实测值，改之前先读）

| 项 | 值 | 来源 |
|---|---|---|
| 输出图宽度 | **1200 px** | Playwright viewport 600 × device_scale_factor 2 |
| 实际内容宽度 | **560 CSS px** | 600 减去 body 的 `padding: 20px` 左右共 40 |
| 模板的 `max-width: 680px` | **不起作用** | viewport 只有 600，body 先被卡住了 |

560px 的含义：**表格最多 4 列**，每列净可用不到 100px。

## 结构

```
# 市场环境日报　2026-09-15

**券商终于干活了，情绪从冰点起飞　——就是活跃市值还没醒**

## 市场闸门          （活跃市值 K 线 + 读数表 + 指数表）
## 今日的反转信号      （券商共振 / 游资进场 / 情绪起飞 + 涨停折线）
## 未变的约束          （与反转信号对照，说明为什么还不能当趋势反转）
## 上证指数形态        （K 线图 + 形态/量能/位置三段简评）
## 分钟级结构          （30 分钟 K 线 + MACD + 背离 + 各周期状态）
## 资金风向与板块      （新高折线 + 行业分布 + 主线 + 术语旁注）
## 操作含义            （能做什么 / 不能做什么 / 失效条件）
```

标题按**当期实际内容**起名，不必逐字照抄——上面是 09-16 那期的骨架，仅供参考结构顺序。

**章节标题不加序号。** 不写「一、市场闸门」这种——编号是呆板的列序，而报告的价值在于
标题本身说清了那节讲什么，不需要再排个座次。视觉上靠 `h2` 前的琥珀小色块 + 上下间距
分隔就够了（模板里已定义）。

**章节之间不用横向分割线**——理由同上，靠间距分隔。

### 开头那句总览：**说人话，别说官话**

副标题（h1 下面那行加粗）是整张图**唯一会被所有人读到的句子**——很多人只扫这一行。
所以它要像人说话，不要像公告。

```
✗ 三重反转信号出现，四条约束未变　轻仓试错，仓位上限 1~2 成
✗ 空头区间，建议控制仓位，注意风险
✓ 券商终于干活了，情绪从冰点起飞　——就是活跃市值还没醒
✓ 昨天赌一根，今天赌到了　——但机构还在看戏，仓位别上头
✓ 热闹是真热闹，闸门也是真没开　——轻仓凑个热闹
```

要点：

- **拟人 / 口语**（「干活」「起飞」「没醒」「看戏」）。市场里的角色可以当角色写：
  券商、活跃市值、游资、机构各有各的动作
- **破折号后面放反差**。前半句说热的那面，后半句把冷的约束压上来——这个结构最像
  人说话，也最省字
- **俏皮是壳，结论是核**。调侃完必须让人知道「所以呢」——上面三例都落在
  「仓位别上头」「轻仓」上
- **长度控制在一行半以内**。图片副标题超过两行会挤，且失去「一眼扫过」的意义

**不要为了俏皮牺牲准确。** 说「活跃市值还没醒」可以（它确实仍空头），说「要反转了
开玩笑的」不行——那是在信息里掺假。

## 硬性规则

每条都附了成因——**成因不成立时规则才可以改**，不要当教条照搬也不要随手删。

### 1. 标题、表格、列表、引用块的前后各留一个空行

**成因**：`nl2br` 会把单换行变成 `<br>`，不留空行相邻两行会粘进同一个 `<p>`。
`markdown_lab.py:preprocess_markdown()` 只对「`**加粗行**` 或 `##标题` 紧跟列表」
这一种情况自动补空行，其余一概不管。

### 2. 不要用横向分割线

不写 `---`。模板的 CSS 会给每个 `<hr>` 画一条横线，把连续的阅读流切断。

**注意**：模板里 `h1` 自带 `border-bottom`，那是标题下划线、不是分节线——它**去不掉也
不用管**，只要不额外加 `---` 就行。

### 3. 表格不超过 4 列

**成因**：内容区 560px。5 列时每列约 90px，中文标签会折成两行，反而更难读。

### 4. 长数据拆成多行表格，不要挤在一行

12 只指数距 60 线的正确写法是 3 列表格分 12 行。挤成一行会折成 4 行且难以对齐。

### 5. 涨跌数字用 `.up` / `.down` 上色（红涨绿跌）

```html
<span class="up">+1.55%</span>      <!-- 红涨 -->
<span class="down">-1.83%</span>    <!-- 绿跌 -->
```

**不要用 `.positive` / `.negative`** —— 那两个类表达的是语义上的「好/坏」（橄榄绿/陶土红），
个股分析报告在用，与价格方向不是一回事。**涨跌必须红涨绿跌**（A 股惯例）。

**成因**：`md_in_html` 扩展开着，原始 HTML 会透传；这三个类都在模板里定义好了，
不改 CSS 就能用。涨跌数字满屏都是，上色后扫读快很多。只给**数字**上色，不要整行变色。

### 6. 不使用 emoji

**成因**：这是每天的决策材料，不是营销图。用户明确要求严肃。h1 也不带。

### 7. 每章结尾一条 `>` 引用块作小结

**成因**：读者对「每章末尾有一句人话结论」形成预期后，可以只扫引用块快速过一遍。
引用块内容用**口语化的一句话**，不要复述上面的数字。

### 8. 章节顺序：闸门优先

市场闸门必须在最前。**成因**：它回答「要不要参与」，其余章节回答「参与什么」。

### 9. 闸门缺数据必须显式写出，不得省略该章

即使 0AMV 数据缺失，也要保留「一、市场闸门」并写明 `> 活跃市值数据不可用…`。

**成因**：`analyze.py:414` 的纪律——「没看到闸门警告」会被误读成「可以参与」。
这与个股报告「没新闻就略过第 2 章」的做法**相反**，别照搬那边。

## 配图

### 出图

图由脚本生成，不由 AI 画：

```bash
PYTHONPATH=. conda run --live-stream -n stock python -m market.charts 20260915
```

六张图落在 `market_reports/charts/YYYY-MM-DD/`。

### 每张图配在哪一节（**不要随意摆放**）

**图必须紧挨着它要说明的数据**，否则读者看到图时不知道它在讲什么，翻回去又找不到。
这是最容易出的错——2026-09-16 那版就把涨停折线放到了「操作含义」节。

| 图 | 配在哪 | 说明什么 |
|---|---|---|
| `amv.png` | **市场闸门**节 | 活跃市值自身的 K 线走势 |
| `limitup.png` | **情绪那一节** | 涨停家数的日频走势——它出现的段落正是讲「涨停 32→89」的地方 |
| `newhigh_hs300.png` | **资金风向那一节** | 沪深300 创新高占比——**机构**态度 |
| `newhigh_csi2000.png` | **资金风向那一节**（紧接上一张） | 中证2000 创新高占比——**游资**态度 |
| `shindex.png` | **上证形态那一节** | 价格位置与均线 |
| `min30.png` | **分钟级结构那一节** | 上证 30 分钟 K 线 + MACD——背离在图上直接看得见 |

**六张图必须都用到**，少一张就是漏。出图脚本已经生成好了，漏掉只可能是忘了嵌。

**分钟级那节配 K 线是必要的**：那节讲的「底背离」是个**形态**，光看数字（两个低点、
两个柱值）看不出形状，有图才能一眼确认「价格新低、柱的谷抬高」这件事确实成立。

### 嵌入语法

用**仓库相对路径** + `<img>` 标签：

```html
<img src="market_reports/charts/2026-09-15/amv.png" style="width:100%; margin:1rem auto" />
```

**成因**：`convert_local_images_to_base64` 对相对路径按 **cwd** 判断存在性，只要渲染时
cwd 是仓库根就成立（skill 的命令本来就在仓库根跑）。相对路径让 md 可移植、git diff
干净；绝对 `file://` URI 会把用户家目录路径写进 git 跟踪的文件。

不要用 `![]()` 语法——它没法控宽度，1800px 宽的原图会被压得很难看。

### 静默失败陷阱（必读）

**找不到图，渲染器只 print 一句警告就继续**，最终 PNG 里是坏图占位。项目里
`output/中远海能(600026)_分析报告.png` 就是这么坏掉的，而且一直没人发现。

所以：

- `market.charts` 落盘后自带 `assert p.is_file()`
- **渲染完必须自己 Read 一遍图**，确认图表真的显示了，不要只看日志说「已生成」

## 内容要求

> **写完图版后逐项勾选这张表，缺哪项就补。** 这些要求曾被写成描述性措辞，结果
> 2026-09-16 那版把术语解释整节漏掉了——**没有可勾选项的要求就等于没要求**。

| # | 要求 | 怎么算做到了 |
|---|---|---|
| 1 | **六张图各就其位** | `amv` 在闸门节、`limitup` 在情绪节、`newhigh_hs300` 与 `newhigh_csi2000` 在资金风向节、`shindex` 在上证形态节、`min30` 在分钟级节。一张不缺、不串位置 |
| 2 | **术语解释用 `.aside` 旁注块，不用标题、不用 `>`** | 有 `<div class="aside">` 块，首行写「供回顾时参考，不影响上面的判断」，至少覆盖**炸板率、晋级率、基差**三项（当日出现过的才写）。**不要写成 `### 三个术语`**（辅助信息不该有和主分析平级的标题）；**也不要用 `>`**（会与章节小结合并成一个框） |
| 3 | **两个 20 日新高写了含义** | 不只是两个数字——说了度量的是什么、两个口径各代表谁、怎么对比看 |
| 4 | **20 日新高的分母跟着写** | 写成「6/300」而非只写「6」 |
| 5 | **宽基指数是点评不是罗列** | 有 3-4 只的独立点评段落，含走势/成交量/形态，不是一张光秃秃的涨跌表 |
| 6 | **上证形态独立成节** | 三段：形态、量能、位置 |
| 7 | **阶段那节说了打法** | 不只是「空头/箱体」，而是「该用什么打法」，含箱体的资金方向与滞后提示 |
| 8 | **无引用出处** | 全文搜不到「《」与「某某文档的判据」 |
| 9 | **无 emoji、无 `---`** | 符号 `⚠ ◆ ✓` 可用；装饰性 emoji 与横向分割线不可用 |
| 10 | **开头那句说人话** | 副标题是拟人/口语的，破折号后带反差，且落到了「所以呢」。不是「三重信号出现，四条约束未变」这种公告腔 |

### 术语解释（图版同样必写，但**不要用标题**）

炸板率、晋级率、基差这类名词**要给解释**，说清**怎么算**和**怎么读**。

**但不能写成 `### 三个术语` 这种呆板小标题。** 术语是**辅助信息**，给它一个和主分析
平级的标题，读者会以为那是正文的一部分；而它的作用只是「回顾时查一下」。

**用 `.aside` 旁注块承载** —— 模板里已定义好这个类，视觉上比正文弱一档：

```html
<div class="aside" markdown="1">

**术语** —— 供回顾时参考，不影响上面的判断。

**炸板率**　盘中触及涨停但收盘未封住 ÷（涨停 + 炸板）。越高说明追涨越容易被套。今日 11.0%，前日 42.9%。

**晋级率**　昨日涨停中今日继续涨停的比例。衡量赚钱效应的持续性。今日 37.5%，已过 35% 健康线。

**基差**　股指期货 − 现货指数。负值叫贴水，代表期货比现货悲观。今日 IF 贴水 -2.27，分歧不大。

</div>
```

要点：

- **首行点明它是辅助信息**（「供回顾时参考，不影响上面的判断」），读者可以整块跳过
- 每个术语一条，**术语名加粗**顶格，解释紧随——扫读时一眼找到要找的那个
- 放在**首次出现的章节末尾**，不放文档末尾（读者在哪一章碰到哪个词，就在哪一章解释）
- 已在正文里解释过的词**不重复**，避免同一份报告说两遍

**不要用 `>` 引用块写旁注。** 两个相邻的 `>` 块会被 markdown **合并进同一个 blockquote**
——实测术语块会跟章节小结粘成一个框，看起来像是「小结里混进了术语」。
`.aside` 是为此单独加的类，灰色细边 + 小字 + 弱化色，与琥珀色粗边的章节小结
（`blockquote`）形成两级层次：**粗边琥珀 = 本章结论，细边灰 = 可跳过的补充**。

**这条对图版与文字版同等要求。** 2026-09-16 那版图版整节漏掉，是因为它当时只写在
文字版里、图版没照做。术语解释不是「文字版才有的细节」——图版会独立传播，读者
更需要它。

### 阶段那节要说清「该用哪套打法」

「空头区间、仓位 1~2 成」只说了**能做多重**，没说**该用哪套**。对短线的人来说，
「空头等」和「箱体高抛低吸」是完全不同的操作。所以阶段那节必须落到具体打法上。

**箱体震荡要分资金方向**——同样叫箱体，钱在进和钱在走是两回事：

| 资金 | 打法 |
|---|---|
| 流入 | 标准高抛低吸（上沿减、下沿加） |
| **流出** | **只做上沿减仓，不做下沿加仓**（下沿大概率被击穿） |

**必须转达滞后提示**：阶段由 60 线斜率判定，天然滞后——它确认转向时行情往往已走大半。
转向的**领先**信号看活跃市值（单日 ≥+4% 且当日站上 60 日线）。这一条要在报告里写明，
否则读者会把「单边下跌」当成「现在才开始跌」。

### 创新高板块是找方向的入口，不只是情绪温度计

「L2 资金风向」给的是创新高的**广度**（家数占比），「L2 创新高板块」给的是**谁**在突破。
后者才是可操作的：

- 报出前 10 个行业及家数
- 报**前 3 行业集中度**：≥40% 说明抱团集中（方向明确），低说明分散（没有共识）
- 写清「家数」是该行业内创新高的只数，**不是全部成分**

### 两个 20 日新高必须写清含义

报告里不能只丢「沪深300 8/287（2.8%）　中证2000 27/699（3.9%）」两个数字——
它们**度量什么、为什么分两个口径**都要交代：

- **度量的是「突破」**：有多少票的收盘价创了 20 日新高。突破是大概率交易，
  家数多说明往上走的力量在扩散，掉到个位数说明突破能力枯竭
- **分两个口径是因为代表两类资金**：沪深300 成分 = 大盘股 → **机构态度**
  （**中长期投资者更要重视**，机构运行情况决定市场中长期走势）；
  中证2000 成分 = 小盘股 → **游资态度**（衡量短线赚钱效应的关键指标之一）
- **两者对比看资金在哪边**：都高 = 全面进攻；一小一大 = 结构性行情；都低 = 枯竭
- **这是找方向的入口**，不只是情绪温度计：哪类票在创新高，就去对应板块找预案

**分母要写。** 正常情况下它等于成分数（沪深300 = 300、中证2000 = 2000）。
若分母明显偏小（曾出现 287 / 699），**那是名单文件坏了，不是「库里缺票」**——
去查 `datas/stock_index_list.py`，它必须用中证指数公司官方源
（`ak.index_stock_cons_csindex`），不是 `ak.index_stock_cons`。后者返回的行数看着对
但大量重复、同时漏掉真实成分，而且**连带影响分子**（2026-09-17 实测：修正后中证2000
的创新高家数从 27 变成 84）。

### 宽基指数要点评，不是罗列

不要只给一张涨跌表。挑 3-4 只重点讲：当日最强/最弱的、距 60 线最远/最近的，
各自说清**走势、成交量、形态**。其余用表格带过。

### 上证指数形态独立成节

用户明确要求。三段：**形态**（趋势结构、关键均线位置）、**量能**（反弹/横盘期的量能
变化意味着什么）、**位置**（关键位在哪、距离多少）。

### 不要引用规则出处

报告里**不出现**「《某某》说」「某某文档的判据」「参考某某材料」这类引用。
判断要**自圆其说**，靠数据与推理本身站住，不靠权威背书。

```
✗  依据是《十分钟讲透》里 2020-06-01 那个案例，文章判定信号无效
✓  若用大盘 60 线，2020-06-01 那天上证已在自身 60 线上方，信号应当立即生效，
   但实际行情是又横盘许久才启动——只有用 0AMV 自身的 60 线才解释得通
```

**成因**：这是给自己看的决策材料，规则从哪来不重要，**规则怎么用、为什么在这里成立**
