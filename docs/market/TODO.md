## 中：板块资金流入流出（已调研，待实现）

**为什么要做**：交易系统里每日复盘要看「各板块的资金流入流出，拎出流入最多和流出
最少的几个」。这一项现在的报告里没有——我们有涨跌幅、涨停分布、创新高分布，但
**没有资金净额**。同样是「半导体涨 4.79%」，资金净流入 207 亿和净流出 20 亿是
两回事。

### 数据源（2026-09-17 实测）

**同花顺**，两个接口都可用：

```python
ak.stock_fund_flow_industry(symbol="即时")   # 90 个行业
ak.stock_fund_flow_concept(symbol="即时")    # 387 个概念
```

字段：`行业 / 行业指数 / 行业-涨跌幅 / 流入资金 / 流出资金 / 净额 / 公司家数`

**东财那两个不可用**（`stock_sector_fund_flow_rank`、`stock_individual_fund_flow_rank`
均被连接拒绝），同花顺这两个是唯一可用源。

### 已验证的事实（不必重测）

- **单位是亿元**，且 `流入 − 流出 = 净额` 完全自洽
  （半导体 1089.36 − 882.33 = 207.03）
- **量级合理**：全行业流入+流出合计 12,209 亿，全市场成交额 18,498 亿，比值 0.66。
  不吻合 100% 是因为同花顺只覆盖 90 个行业、且「主动买卖」本身是估算口径
- **数据可信**：09-16 实测流入前三 = 半导体(207.03 亿)、通信设备(150.63 亿)、
  元件(42.01 亿)，与当日视频复盘说的「半导体、通信设备和元件」完全一致

### ⚠️ 硬约束：**没有日期参数，补不了历史**

函数签名是 `(symbol: str = '即时') -> DataFrame`，`symbol` 可取：

| 取值 | 含义 |
|---|---|
| `即时` | 当日 |
| `3日排行` / `5日排行` / `10日排行` / `20日排行` | **累计**排行，不是历史单日 |

所以它和 `market`、`boards_em` 同类，**只能在当天抓**。哪天忘了抓，那天就永远缺了
（09-16 的快照是隔天补的，因此没有这一项）。

**实现时要放在 `fetch_snapshot` 的「仅当天」那一组**，并在报告里对历史日期标注
「该接口无历史参数」。

### 要定的设计选择

**用行业还是概念？** 建议**行业为主**：

- 现有的超跌板块、创新高板块都是按 `stock_base_info.idn_name`（90 个行业）做的，
  资金流也用行业才能**横向对齐**——同一个板块的涨跌、涨停、创新高、资金净额放在
  一起看才有意义
- 概念口径 387 个，更贴题材炒作但噪声大，且与现有板块分析对不上

概念口径可作为可选项，但不要作为主力。
