# 波段持仓每日监控

脚本测客观值，你按交易系统做定性研判。这是每天真正会用的东西，写给「五分钟内决定今天动不动手」的场景。

## 运行环境

```bash
cd /Users/qianqian/stock/AshareLab
conda run --live-stream -n stock python -m portfolio.monitor
```

`--live-stream` 必需，否则 `conda run` 缓冲输出到进程结束。

```bash
# 指定代码（自选股 / 账本还空着时试跑，不算盈亏）
... -m portfolio.monitor --codes 300314,002594
# 历史某天（复盘用）
... -m portfolio.monitor --date 20260828
# 机器可读
... -m portfolio.monitor --json
```

数据来自本地 `database/ashare_data.db`（前复权日线）。**先确认行情是最新的** —— 报告顶部的日期若不是最近交易日，先跑 `/qk-stock-daily-update`。

## 工作流

1. 跑脚本拿测量值。
2. 读 `references/sell_rules.md` —— 卖点规则、止损口径、指标读法、**三个已知的规则冲突**。必读，尤其冲突那节，那是你要做判断的地方。
3. 按下面的组织方式输出日报。
4. 有价值的判断当场记成便签（见「顺手记便签」）。

## 输出组织

**按「今天要不要动手」排，不按股票罗列**（设计决策 D11）。脚本已经给了 `urgency` 三档，那是机械判定的起点，**你可以重新权衡** —— 但改档要说理由。

```
一句话总览：几只持仓，今天几只要动手，整体浮动多少
        ↓
## 需操作 —— 展开细节，每只给明确动作
        ↓
## 需观察 —— 展开细节，给「看什么、什么条件下动」
        ↓
## 无事持有 —— 每只一行带过
        ↓
## 今日需人工确认
```

### 每只票的细节写法

**第一行放跟踪对照**，不是指标。脚本给了 `notes_recent`，把「我当时的判断」和「今天的走势」对上：

```
### 300314 戴维医疗  收 11.53（-0.60%）  持 2000 股  成本 12.29  浮动 -6.18%
跟踪：8-25 买入时写「完美一，等黄线不破就拿住」→ 黄线 11.45 至今未破（现价上方 0.70%），
      当时的判断条件仍然成立；但便签没预料到会连续 6 日收在白线下。
```

指标随时能算，判断对照只有存了便签才有 —— 这是整个流程的核心价值，别放到最后。

然后才是位置与信号，**只写有信息量的**：

- 止损：对照 `stop_plan`（我当初写下的），是否触及、距离多少。`stop_adjust_count` >0 要点出来
- 卖点信号：BBI 离场、止盈放飞、白黄死叉，带具体天数与数值
- 出货：`distribution` 的分级与形态编号，注意 `invalidated`（换庄失效）与 `composite`（复合头部）
- 指标位置：J 值与方向（走平/翘头是关键，不只是数值）、周线 J、MACD 三层
- 量能异动

最后给**动作 + 失效条件**：

```
动作：黄线 11.45 是这笔的底线，今日未破则继续持有，不因 BBI 已失守而提前走。
失效条件：收盘跌破 11.45 且次日无法收回 → 按 8-25 的计划离场。
```

### 判断纪律

- **显式引用证据**：日期 + 数值。「量能萎缩」不算判断，「末日量为点火最大量的 0.091、连续 5 日量比 <0.2」才算
- **规则冲突要摊开讲**，不要选一边悄悄忽略另一边。`references/sell_rules.md` 列了三个已知冲突及权衡要点
- **区分「规则说什么」和「我建议什么」**。规则原文照报，你的权衡另说，别把两者混成一句
- **不做收益预测**。可以说形态强弱与条件是否成立，不说「预计涨 X%」
- **数据只到评估日**，不要用之后的走势验证判断（除非明确在做历史复盘）
- **止损下移要点名**。`stop_adjust_count` 是自欺的可靠探针，看到就说

### 用词

`按计划执行止损` / `减仓` / `继续持有` / `观察待定` / `条件未成立不动`。

避免「建议关注」「可能需要注意」这类没信息量的措辞 —— 每只票都要落到一个明确动作或明确的观察条件。

## 顺手记便签

监控中形成的判断要存下来，否则下次没有对照基准：

```bash
conda run --live-stream -n stock python -m portfolio.cli note 300314 \
  "BBI已失守但黄线11.45未破，判断是洗盘尾段；跌破且次日不收回则走" \
  --type 交易计划 --status 待验证 --due 20260915 --commit
```

止损计划有变化时（**追加留痕，不覆盖**）：

```bash
... -m portfolio.cli stop 300314 "上移到点火后低点 11.84" --price 11.84 --basis 人工 --commit
```

`pending` 里的待验证便签，到期了要在日报里回看并给结论 —— 应验还是证伪。验证后改 `status`（目前需手工编辑 `portfolio/swing/notes.jsonl`）。

## 存档

日报写完存到 `portfolio/swing/daily/YYYY-MM-DD.md`（设计决策 D6），用评估日日期。同一天重跑覆盖同名文件。

存档结构：总览 → 三档分组 → 需人工确认 → 附脚本原始测量（折叠或放末尾，供回溯）。

## 尚未覆盖的部分
