# 单笔买入复盘

复盘「我在这笔交易里买得对不对」，不是「这张图是不是好 B1」。区别在于多了成交价、当时的理由和事后走势。

## 与 `/qk-stock-b1-review` 的分工

| | qk-stock-b1-review | 本 skill |
|---|---|---|
| 问题 | 这张图是不是好的 B1 买点 | 我这笔买入做得怎么样 |
| 视角 | 静态体检，只看图 | 四方对照：图 + 成交价 + 我的理由 + 事后走势 |
| 需要 | 代码 + 日期 | 一笔交易记录（或 `--sim` 试算） |

本 skill **复用** `b1_review.py` 的全部测量，不重复实现 —— 所以「买点当时的测量」那段输出和 b1-review 完全一致，你按同一套标准评价。

## 运行环境

```bash
cd /Users/qianqian/stock/AshareLab
conda run --live-stream -n stock python -m portfolio.review <股票名或代码>
```

`--live-stream` 必需，否则 `conda run` 缓冲输出到进程结束。

```bash
# 默认复盘该票最近一笔买入
... -m portfolio.review 300314
# 指定某笔（一票多次买入时）
... -m portfolio.review 300314 --trade T20260825-300314-1
# 没有成交记录时试算：假设某日某价买入
... -m portfolio.review 300314 --sim 20260825 12.29
# 只看到某天为止的事后走势（避免用更晚的走势"作弊"）
... -m portfolio.review 300314 --date 20260901
```

## 诚实前提（重要）

**这是事后复盘，不是事前依据。**

本流程有意没有事前计划层（设计决策 D8：每笔买入先记计划太繁琐）。所以脚本给出的测量值是**复盘时算出来的**，不代表买入当时你真看过这些数。

因此：

- 不要说「这笔交易符合规则，是规则内交易」—— 没有事前记录，无法判定
- 可以说「这笔买入在事后测量上落在 B1 完美一的形态里」
- 便签里的买入理由是唯一的事前证据，**它才是判断「当时怎么想」的依据**，测量值只是对照
- 核心原则第二条禁止「交易后从指标里挑理由」。复盘的价值在于积累「我的买点质量分布」，不是为已成交的交易背书

这个区分要在报告里保持住，不要滑向事后合理化。

## 工作流

1. 跑脚本。
2. 读 `qk-stock-b1-review/references/b1_rules.md` —— 买点质量的评价基准（十案例标定表）。**必读**。
3. 若涉及卖点或持仓去留，再读 `qk-stock-swing-daily/references/sell_rules.md`。
4. 按下面五段输出。

## 输出结构

### 1. 一句话结论

这笔买入的质量定级 + 最关键的一个数字。

评级用词：`买点优秀，执行到位` / `买点成立，但买贵了` / `买点勉强` / `不构成 B1，属系统外交易` / `买点对，但止损纪律没守住`。

**买点质量和交易结果是两件事**，要分开说。买点优秀但亏了，和买点勉强但赚了，复盘结论完全不同 —— 前者是可重复的正确决策，后者是不可重复的运气。

### 2. 买点质量

按 `b1_rules.md` 的三层体系评（硬门槛 → 形态链条 → 图形归类），标准和 `/qk-stock-b1-review` 一致。带具体数字。

### 3. 执行质量（本 skill 的核心）

看 `买入价偏离` 段：

- **vs 当日收盘%**：B1 是收盘信号，买在收盘之上多少就吃掉多少容错空间。长期看这个数能看出「我习惯追高多少」
- **单笔风险敞口%**：买入价距止损位的距离。这是这笔的最大亏损，也是仓位该多大的依据
- **买入价在点火区间位置**：越低越好，>0.5 说明买在区间上半部

再看 `止损沿革`：

- 有没有止损计划？（没有 → 违反核心原则，要点名）
- 调整过几次？**止损下移是自欺的可靠探针**，看到就说
- 事后走势里的「止损触及」是按沿革**逐日取当时生效的那条**判定的，不是拿最新止损回溯套用

### 4. 事后走势对照

`事后走势` 段回答两件事：

- **当时的判断应验了吗？** 拿便签里写的条件对照实际走势。「等黄线不破就拿住」→ 黄线破了没？
- **先触最高还是先触最低？** 先高后低是「该走没走」，先低后高是「拿住就对」。这决定复盘结论是「卖点问题」还是「心态问题」

如果止损被触及但持仓还在，这是最需要点出来的 —— 计划写了没执行。

### 5. 可迁移的结论

这笔交易教会了什么，要能用到下一笔。写成具体条件，不要写成感想。

好的结论：「点火后 7 天 +51% 的票，回撤到区间 0.2 仍在跌，说明前期涨幅高的票洗盘时间要按 10 个交易日以上预估，不能按 4 天」

差的结论：「要耐心持有」「下次注意风险」

## 判断纪律

- **显式引用证据**：日期 + 数值
- **买点质量与交易结果分开评**（见上）
- **不用事后走势反推买点对错**。买点评价只看成交日及之前的数据，走势归走势
- **不做收益预测**
- 只看价量数据，基本面、消息面、板块环境都不在视野内，末尾列「需人工确认」

## 复盘后记一笔

结论要存下来，否则下次没有对照基准：

```bash
conda run --live-stream -n stock python -m portfolio.cli note 300314 \
  "复盘：买点完美一无瑕疵，但买在收盘价上方2.3%，容错被吃掉一半；前期涨幅51%的票洗盘要按10日以上预估" \
  --type 复盘结论 --commit
```

若复盘发现原买入理由已证伪，把那条便签的 `status` 改成「已验证」并说明（目前需手工编辑 `portfolio/swing/notes.jsonl`）。
