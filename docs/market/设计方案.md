# 市场环境分析 — 设计方案

> 状态：v1.0，执行版
> 日期：2026-09-10
> 定位：判断**当前市场环境**（情绪周期、资金风向、主题结构），为选股与仓位提供客观参考。主题/主线识别是其中一层，不是全部。
> 独立于波段持仓流程（`docs/swing/`），暂不与 B1 选股衔接。

---

## 0. 这套东西回答什么问题

按重要性排，每层都能独立回答一个问题：

| 层 | 回答 | 影响 |
|---|---|---|
| L1 情绪周期 | 现在能不能做、做多重 | 仓位基调 |
| L2 资金风向 | 该做大票还是小票 | 选股池方向 |
| L3 主题结构 | 资金在炒什么 | 候选范围 |
| L4 主线判定 | 哪个是主线、哪些是支线 | 优先级与回避 |

**不做**的部分：个股选股（L5，等和 B1 衔接时再说）、盘中实时（只做盘后）、新闻舆情（涨停原因已是资金用脚投票的结果，比新闻硬）。

## 1. 两份方案的合并说明

本方案由两份前置材料合并而来，决策留痕在此，避免以后重复讨论：

- `设计方案调研.md` —— 框架完整（四层流水线、情绪状态机、阈值表），但配套代码有多处会致错的缺陷
- 2026-09-09 的第一版实现（`market/` 包前身）—— 数据管道已验证可跑，但情绪判断层是拍脑袋的

### 1.1 采纳调研版的部分

| 采纳项 | 理由 |
|---|---|
| **`push2delay` 域名** | 关键发现。`push2` 主域名对板块接口断连（实测 8 次全失败），`delay` 域名正常：504 概念 + 496 行业，带 `BK` 代码可取成分股，且与涨停池同属东财口径 |
| **赚钱效应指标** | 第一版最大缺口。晋级率 + 昨日涨停溢价直接度量「打板资金实际赚不赚钱」，比涨停家数更本质 |
| **情绪五段状态机** | 冰点/启动/发酵/高潮/退潮，各带仓位建议，比第一版 4 个 label 更可操作 |
| **强制环比** | 「单日截面容易误判」正中第一版的病：涨停走势 93→73→48 递减，绝对数 42 却给 68 分高分 |
| **板块黑名单** | 宽基/融资融券/基金重仓/昨日涨停不是题材，会污染榜单 |
| **梯队完整性作主线硬条件** | 连板龙头 + 首板同在，说明资金分层而非单股独立行情 |
| **局限性章节** | 照搬精神：接口非官方、概念归属有误差、无法预判突发催化 |

### 1.2 改掉调研版的部分

| 分歧点 | 调研版 | 本方案 | 理由 |
|---|---|---|---|
| 成交额权重 | 绝对分位占 30%，主线判定再加「前 20%」 | 用**环比放大倍数**，且不重复计入 | 成交额绝对值高的多是大市值权重板块而非题材主线；同一因子算两遍 |
| 主题口径 | 概念板块榜（504 个）为主 | **涨停归属为主口径**，板块榜作交叉验证 | 一只票同属几十个概念，概念榜涨幅是成分平均，易被单只暴涨股拉动。涨停是真金白银投的票，归属明确 |
| 判定方式 | 加权总分（30/30/25/15） | **硬规则分层**，总分只用于同层内排序 | 呼应核心原则五「每个指标承担独立职责，避免同源指标重复确认」。权重从何而来无从解释、无从标定 |

### 1.3 调研版代码的实际缺陷（不采用其实现）

记录在此以免有人照抄：

1. **主线列表几乎永远为空** —— `zt_density=0`、`leader_score=0` 写死，40% 权重是死的；剩下 60% 经 MinMaxScaler 后第一名满分也只有 60 分，恰好卡在 `max(60, top1*0.8)` 阈值边界
2. **字段请求与读取不匹配** —— `fields` 未含 `f14`，代码读 `item["f14"]` → KeyError
3. **`data["diff"]` 当列表用** —— 新版接口返回 dict，实测撞 `TypeError: unhashable type: 'slice'`
4. **MinMaxScaler 不适用于成交额** —— 重尾分布（光纤 1655 亿 vs 第四代半导体 27 亿），线性归一化后绝大多数板块挤在 0 附近；应用排名分位
5. **涨停池 URL 缺参数** —— 无 `date`/`pagesize`/`sort`，裸调拿不到数据
6. **无历史库** —— `prev_zt_cnt=None` 写死，退潮期/启动期分支永远不触发，而这两个最需要
7. **分页缺失** —— 板块接口每页硬上限 100，`pz=600` 无效，必须翻页（本方案已实现）

### 1.4 新增：modoo 的大小票分歧法（两份方案都没有）

来源 `trading_system/reference_articles/modoo/大富翁游戏是怎样练成的(4)`：

> 看**中证 2000 的 20 日新高**，看游资们对小票炒作的态度。还有我们的**沪深 300 创 20 日新高**，代表着机构们的看法。以及涨跌家数代表着主要的情绪变化。

底层逻辑（原文）：「我们的优势交易就是做突破，创 20 日新高就是一种突破」—— 衡量两拨资金各自在多大范围上做突破。

**补的是两份方案共同的盲区**：涨停数、炸板率、晋级率全是短线游资口径，看不见机构在干什么。这个指标能回答「现在该做小票题材还是大票主线」，直接影响主线该往哪个池子找。

两个实现优势：**纯本地日线库计算，不依赖任何外部接口**；可任意回溯做阈值标定。

> 澄清一点：modoo **不看**大小票涨停数拆分（他表格里涨停是单一总数），大小票分歧靠两个指数的创新高家数对比。

## 2. 数据源（2026-09-09 实测）

| 源 | 内容 | 历史日期 | 状态 |
|---|---|---|---|
| 东财涨停/炸板池（`push2ex`） | 连板数、封单、首封时间、所属行业 | ✅ 支持 | 稳定 |
| 东财昨日涨停池 | 算晋级率与溢价 | ✅ 支持 | 稳定 |
| 本地日线库 + 指数名单 | 大小票创 20 日新高 | ✅ 任意回溯 | 无外部依赖 |
| 东财板块榜（`push2delay`） | 504 概念 + 496 行业，带 BK 代码 | ❌ 仅当天 | 需翻页 |
| 乐咕市场活跃度 | 涨跌家数、真实涨停跌停、活跃度 | ❌ 仅当天 | 值带 `%` 需剥离 |
| 同花顺行业 90 / 新浪概念 175 | 降级备份 | ❌ 仅当天 | 备用 |
| 东财板块榜（`push2`） | —— | —— | ❌ 断连不可用 |

**关键工程约束**：实时接口（板块榜、情绪总览）无历史参数，**抓历史日期时不能存**，否则会把今天的数据写进历史档、污染持续性分析（第一版踩过，已修）。历史快照只含支持日期参数的源。

## 3. 分层设计

### L1 情绪周期（五段状态机）

必须**环比**判断，单日截面会误判。

| 指标 | 强 | 中 | 弱 |
|---|---|---|---|
| 真实涨停家数 | >60（≥80 狂热） | 30~60 | <30 |
| 最高连板高度 | ≥5 板 | 3~4 板 | ≤2 板 |
| 炸板率 | <25% | 25~40% | >40% |
| 晋级率 | >50% | 35~50% | <35% |
| 昨日涨停溢价（中位数） | >+3% | 0~+3% | <0 |
| 涨跌家数比 | >2 | 0.5~2 | <0.5 |

状态与仓位建议：

1. **冰点期**：跌停 ≥15、涨停 <30、高标 ≤2 板 → 空仓等新题材拐点
2. **启动期**：涨停回暖、出现新龙头、温和放量 → 小仓试错
3. **发酵期**：高度 ≥5 板、涨停 40~120、晋级率上行 → 主线可重仓
4. **高潮期**：涨停 ≥80、炸板率 <25%、全面亢奋 → 边打边撤
5. **退潮期**：涨停环比大幅下滑、晋级率 <35%、炸板率走高、高标断板 → 降仓观望

**溢价用中位数不用均值**：实测 09-09 均值 +1.11% 而中位 -0.60%，方向相反 —— 少数连板股拉高均值，多数昨日涨停股实际是绿的。

### L2 资金风向（大小票分歧）

沪深 300 与中证 2000 的创 20 日新高家数与占比：

- 小票占比 − 大票占比 > 2pct → **小票占优**（游资活跃，做题材）
- 差值 < −2pct → **大票占优**（机构主导，做主线权重）
- 其间 → 均衡

口径说明：按**收盘价**创新高（收盘 = 近 20 日最高收盘）；行情软件若用最高价口径家数会略多。指数成分用当前名单快照，回溯早期有成分变动偏差。

### L3 主题结构

主口径 —— **涨停归属聚合**：

- 涨停行业分布（家数、最高连板、封单合计、代表股）
- 连板梯队（各连板层级的家数与个股）
- 涨停题材延续性（N 日中有几天进入涨停家数前列）

交叉验证 —— 板块榜（概念 + 行业，已过滤黑名单）：当日涨幅榜、成交额环比、板块内涨跌家数、领涨股。

### L4 主线判定（硬规则分层）

**主线**需同时满足：

1. **梯队完整** —— 板块内同时有连板龙头（≥3 板）和首板个股
2. **多日持续** —— 近 5 日中 ≥3 日进入涨停家数前列
3. **赚钱效应为正** —— 该板块昨日涨停股今日溢价中位数 > 0
4. **资金环比放大** —— 板块成交额高于前 5 日均值

**支线**：满足 1~2 条 → 观察，小仓博弈。
**冷门**：其余 → 不参与。

情绪适配：退潮/冰点期主线降级；发酵/高潮期权重拉满。

同层内用总分排序（涨停家数、高度、封单、涨幅综合），但**分层由硬规则定**，总分不参与分层。

## 4. 实现

```
market/                      # 独立包，不依赖 portfolio / hunters
  fetch.py                   # 数据抓取与快照存档
  analyze.py                 # 分层分析
  cli.py                     # snapshot / backfill / report / history
  history/YYYYMMDD.json      # 每日快照，入 git

docs/market/
  设计方案.md                 # 本文件（执行版）
  设计方案调研.md              # 前置调研，保留作档案
```

命令：

```bash
conda run --live-stream -n stock python -m market.cli snapshot        # 盘后抓当日
conda run --live-stream -n stock python -m market.cli backfill --days 30  # 回溯补抓
conda run --live-stream -n stock python -m market.cli report          # 分析报告
conda run --live-stream -n stock python -m market.cli history         # 快照清单
```

**回溯 30 个交易日**：状态机的环比与持续性统计都需要多日数据，一次补齐；同时可用历史数据标定阈值（如看 8 月那波行情各阶段的实际数值）。

## 5. 局限性

1. **无法预判突发催化** —— 政策、黑天鹅、盘中消息会直接改变主线，人工复核不可省
2. **概念归属有误差** —— 个股同属多概念，涨停归属统计有偏差；这是选涨停行业作主口径的原因，但行业口径同样粗
3. **接口是非官方公开接口** —— 字段与地址可能变动；`push2` 板块接口已经挂了一次
4. **只有盘面公开数据** —— 看不到龙虎榜资金意图、盘口暗资金、北向
5. **阈值未经标定** —— 阈值表来自调研版经验值，需用历史数据回验后调整
6. **无盘中数据** —— 只做盘后，`卖点.md` 里「10 点前快速拉升」这类信号看不到
7. **不构成投资建议** —— 客观数据统计与规则判定，实盘决策自行负责
