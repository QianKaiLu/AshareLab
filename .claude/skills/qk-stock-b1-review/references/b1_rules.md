# B1 买点规则与判定优先级

B1 是一个「放量启动后缩量回踩」的买点体系。本文件是判定规则、四类图形的差异，以及十个范本案例的实测标定值。

## 核心逻辑

一句话：从分歧（多空博弈）过渡到一致（缩量企稳）。买点出现在分歧刚转为一致的那一天。

形态链条，顺序不能乱：

```
放量启动（点火，主力建仓波突破黄线）
  → 顶部无量（启动波是量能峰值，之后不再放量）
    → 缩量至地量（洗盘，成交量阶梯式下降）
      → 小阴小阳企稳（分歧转一致，即买点当日）
```

术语对照：

| 术语 | 含义 | 代码字段 |
|---|---|---|
| 大哥 / 主力 | 控盘资金 | — |
| 黄线 | 长期成本线（主力成本），MA14/28/57/114 均值 | `z_yellow` |
| 白线 | 短期均线，收盘价双重 EMA(10) | `z_white` |
| 勾到大幅值 | KDJ 的 J 值探到低位负值区 | `kdj_j` |
| 点火 / 异动 | 放量启动那一波 | `fire_date` / `fire_days` |
| 地量 | 成交量萎缩到近期极低水平 | 末日量在近 60 日分位 |
| 红肥绿瘦 | 阳线强于阴线（本义指**实体**，实务也用成交量） | 量比 / 实体比 |

## 判定优先级

**Tier 1 — 硬门槛**（不满足则不是 B1 买点）

1. 当日涨幅 ∈ [-2%, +1.8%]（小阴小阳企稳）
2. 当日振幅 ≤ 7%
3. 白线 > 黄线
4. 量能相对前期高点呈极致缩量

**Tier 2 — 形态链条**（决定这是不是真的 B1，权重最高）

5. 有明确的放量启动段（点火）
6. 顶部无量：点火后不再出现同等量能
7. 缩量至地量：末日量处于近期低位
8. 关键支撑未破：黄线支撑有效。容许「跌破后快速收回」，这是**强**支撑信号，比从未跌破更积极

**Tier 3 — 指标精准度**（区分图形类型，不是通过与否）

9. J 值 ≤ 13 为标准形态；13~16 属「模糊认定买点」
10. **量能优先于绝对指标** —— J 值不达标但量能反转明确时仍可介入

**Tier 4 — 情境修正**（影响预期与仓位，不影响是否成立）

11. 前期涨幅决定洗盘预期：浮盈少 → 洗盘浅（可能只横盘 4 天）；涨幅高 → 洗盘时间更长
12. 高位票（近 60 日翻倍）走完美四逻辑：止损改用白线、仓位压缩

## 四类图形

| | 核心特征 | 指标要求 | 洗盘方式 | 范本后续涨幅 |
|---|---|---|---|---|
| 完美一 | 标准缩量回调 | 严格（J≤13、极致缩量） | 圆弧洗盘 / 缩量杀跌 | 80% / 67% |
| 完美二 | 变量型洗盘，时间换空间 | **模糊**（无需绝对精准） | 阶梯缩量 / 长期横盘 / 浅度洗盘 | 89% |
| 完美三 | 异动后箱体横盘 | 中等 | 窄幅箱体 + 红肥绿瘦 | 111% |
| 完美四 | 高位缩量上涨、高控盘 | 宽松 | 无深度洗盘（缩量上涨） | 50% |

关键差异：

- **完美二不追求指标精准。** 只要量能缩量 + 黄线支撑就可以试错介入，不必为等一个完美指标而错失机会
- **完美三是完美一的结构变形** —— 压缩的 N 型结构，把横盘区间拉伸即为完美一的标准 N 型
- **完美四是缩量上涨，不是缩量回调。** 股价贴着高位走，所以「现价处于点火区间下半部分」这条对它不适用；也因为离黄线远，止损才要改用白线

从这张表读出的标定信息：

- **J 值跨度极大**（-13.42 ~ 13.73），且与后续涨幅无明显关系。J 值只是入场过滤，不是质量指标
- **涨跌幅全部落在 [-1.91%, +1.80%]**，紧贴区间边界，说明这条硬门槛确实被严格执行
- **振幅集中在 1.88%~4.10%**，昂利康 7.02% 是唯一例外，正好压在 7% 上限
- **白/黄比多在 1.02~1.10**，昂利康 1.314 显著更高 —— 这就是它离黄线远、需改用白线止损的量化体现
- **涨幅最大的三个案例（111%、89%、80%）分属完美三、二、一**，跨类型。类型不预示收益

## 止损与仓位

- 贴近黄线（距离 ≤15%）→ **黄线**为止损位。黄线是主力成本线，跌破意味着建仓逻辑失效
- 远离黄线（距离 >15%）→ **白线**为止损位。否则止损空间过大，单笔风险失控
- 点火首日最低价（`support_price`）是另一个参考位，通常比黄线更近，适合更激进的止损
- 仓位与止损距离成反比。完美四这类离黄线远的，参考比例是总仓位的 5%（100 万仓位买 5 万）

## 判定原则

**量能优先于绝对指标。** 指标不完美但成交量从放量快速缩到地量，形成量能反转信号，且股价回踩黄线确认支撑有效 —— 这种情况成立。反过来，J 值再漂亮，量能没缩下来就不是 B1。

**买点不等于立刻发财。** B1 之后需要耐心等趋势确认，不要因短期波动提前离场。

**浅度洗盘容易误判。** 前期涨幅低、浮盈少的票，主力不需要深度洗盘，横盘几天就够。很多人在横盘期间离场，判断洗盘幅度要先看前期浮盈。

**洗盘时长与前期涨幅正相关。** 前期涨幅高则横盘洗盘时间更长，时间换空间越充分，后续上涨动能越足。

**高控盘的特征是「窒息」。** 缩量上涨、顶部无放量，说明主力没出货。走势波动极小看似沉闷，实则是分歧极小的表现。这类属于激进试错买点，做错也要做，但仓位必须控制。

**红肥绿瘦的本义是实体。** 阳线实体大于阴线实体，同时收盘价反复精准贴近白线，是主力精准控盘的痕迹。实务中也用成交量口径衡量，两者取其一即可。
