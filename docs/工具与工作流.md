# 工具与工作流

本仓库的 skill 速查：每个干什么、怎么用、什么时候用。末尾有一套每日流程示例。

命令一律在 conda `stock` 环境下跑，`--live-stream` 必需（否则 `conda run` 缓冲输出到进程结束，看起来像卡死）。

---

## 一、股票分析

### `/qk-stock-daily-update` — 行情日更

**干什么**：同步股票池（补新股、剔退市）→ 增量抓日线 → 回填换手率 → 数据质量校验。

**所有其它分析的前置**。库不是最新的，后面全部白算。

```bash
PYTHONPATH=. conda run --live-stream -n stock python workflow/daily_update.py > logs/daily_$(date +%Y%m%d).log 2>&1
```

耗时 35 秒~20 分钟（视落后天数），**必须后台跑**。读日志尾部「=== 校验 ===」段确认最新交易日与异常数。落后几只（停牌股）正常。

参数：`--dry-run` 只看不写、`--force-pool` 强制刷股票池、`--skip-pool` 跳过股票池同步。

### `/qk-stock-b1-daily` — 全市场 B1 扫描

**干什么**：扫全市场找 B1 买点（放量启动后缩量回踩），按量能链分三个梯队，交叉指数成分，存档到 `b1_results/YYYY-MM-DD.md`。

**找新机会用**。回答「今天有哪些票值得看」。

```bash
PYTHONPATH=. conda run --live-stream -n stock python -m hunters.z_b1_hunter > logs/b1_hunt_$(date +%Y%m%d).log 2>&1
```

约 3 分钟，后台跑。命中 40~80 只属正常范围（2026-09-04 只有 34 只，说明机会偏少）。

### `/qk-stock-b1-review` — 单股 B1 体检

**干什么**：单只票在某天是否构成优秀 B1，给图形归类（完美一/二/三/四）和止损方案。

**静态看图用**。从 b1-daily 的名单里逐个细看时用这个。

```bash
conda run --live-stream -n stock python .claude/skills/qk-stock-b1-review/scripts/b1_review.py 300314
conda run --live-stream -n stock python .claude/skills/qk-stock-b1-review/scripts/b1_review.py 宁波韵升 20250806
```

评价基准在 `references/b1_rules.md`（十案例实测标定表），那是「优秀 vs 勉强」的量化参照。

### `/qk-stock-distribution` — 主力出货识别

**干什么**：识别五种出货形态（S1 天量巨阴 / S2 次高点巨量长阴 / S3 阶梯放量下跌 / S4 双头双放量巨阴 / S5 绿肥红瘦），输出「必走 / 至少走一半 / 稳一手」分级。

**排除风险用**。买之前筛掉有出货嫌疑的，持仓中检查要不要走。

```bash
# 批量：给代码、给文件、给指数池
... distribution_scan.py --codes 600016,300251
... distribution_scan.py --file b1_results/2026-09-04.md
... distribution_scan.py --pool hs300
# 单股复核（顶部区逐根 K 线明细）
... distribution_review.py 600016 20250815
```

脚本在 `.claude/skills/qk-stock-distribution/scripts/` 下。

### `/qk-stock-0amv` — 活跃市值手工录入

**干什么**：指南针 0AMV（活跃市值指数）没有公开接口，只能人工读数录入，落 `manual_data/0AMV.csv`。

**择时与仓位用**：入场看 4% 阳线（小波段）/ 5~8%（大波段）；单日跌幅 ≥2.3% 大概率波段结束。

```bash
conda run --live-stream -n stock python .claude/skills/qk-stock-0amv/scripts/amv_store.py show
```

**当前还没有任何录入**（`manual_data/` 目录尚未创建，首次 `add --commit` 时自动建），没录入前所有依赖它的判断都跳过。

## 二、波段持仓（swing 系列）

三个平级 skill 共享 `portfolio/` 这一个 py 包。数据落 `portfolio/swing/` 的 JSONL，入 git。

设计与决策记录见 [swing/需求文档.md](swing/需求文档.md)。

### `/qk-stock-swing-trade` — 记一笔

**干什么**：口语化成交描述 → 结构化记录。买卖、买入理由、止损计划、便签验证。

```bash
# 买入（必带止损计划，核心原则）
conda run --live-stream -n stock python -m portfolio.cli buy 300314 12.29 1000 20260825 \
  --stop "跌破黄线11.16且次日不收回则离场" --stop-price 11.16 --basis 黄线 \
  --reason "完美一，末日量0.091地量" --due 20260910 --commit

# 卖出（清仓时自动归档到 closed/<code>.md）
... -m portfolio.cli sell 300314 13.50 1000 --reason "BBI上第二根中大阳，止盈放飞" --commit

# 改止损（追加留痕，下移会警告）
... -m portfolio.cli stop 300314 "上移到 11.84 保本" --price 11.84 --basis 人工 --commit

# 便签与查询
... -m portfolio.cli note 300314 "今日缩量十字星，等黄线表态" --type 交易计划 --commit
... -m portfolio.cli verify N20260825-300314-1 "黄线未破，判断成立" --commit
... -m portfolio.cli show                    # 持仓总览
... -m portfolio.cli detail 300314           # 单票交易/便签/止损沿革
... -m portfolio.cli pending                 # 未验证便签
```

**写入默认只预览，加 `--commit` 才落盘。**

### `/qk-stock-swing-daily` — 每日持仓日报

**干什么**：止损对照、卖点信号、出货识别、便签跟踪，按「今天要不要动手」分三档（需操作 / 需观察 / 无事）。

**每天真正会用的那个**。

```bash
conda run --live-stream -n stock python -m portfolio.monitor
# 账本还空着时，指定代码试跑
... -m portfolio.monitor --codes 300314,002594
# 历史某天复盘
... -m portfolio.monitor --date 20260828
```

卖点规则与三个已知规则冲突见 `references/sell_rules.md`。

### `/qk-stock-swing-review` — 单笔买入复盘

**干什么**：四方对照 —— 买点质量 + 成交价偏离 + 当时写的理由 + 事后走势。

**回答「我这笔买得对不对」**，区别于 b1-review 的「这张图好不好」。

```bash
conda run --live-stream -n stock python -m portfolio.review 300314
# 指定某笔（一票多次买入）
... -m portfolio.review 300314 --trade T20260825-300314-1
# 没录入记录时试算
... -m portfolio.review 300314 --sim 20260825 12.29
```

**这是事后复盘，不是事前依据** —— 本流程没有事前计划层（决策 D8），所以不能据此判定「规则内交易」，只能说事后测量上是否落在 B1 形态里。

## 四、经典每日工作流

### 收盘后（约 15 分钟，大部分时间在等后台任务）

```
1. /qk-stock-daily-update            更新行情（后台，35秒~20分钟）
        ↓  必须等完成，否则后面全部基于旧数据
2. /qk-stock-swing-daily             看持仓：今天要不要动手  ← 最重要
        ↓
3. 有操作 → /qk-stock-swing-trade    记一笔（买卖 + 理由 + 止损）
        ↓
4. /qk-stock-b1-daily                找新机会（后台，约3分钟，可选）
        ↓
5. 候选票 → /qk-stock-b1-review      逐个体检
        ↓
6. 准备买的 → /qk-stock-distribution 排除出货嫌疑
```

**顺序有讲究**：先看持仓再找新票。持仓是已承诺的风险，新机会是可选的 —— 反过来容易在还没处理该走的票时又买入。

### 什么时候可以跳过哪步

- 当天已跑过日更 → 跳过第 1 步
- 空仓 → 跳过第 2、3 步，直接找机会
- 满仓或不打算加仓 → 跳过第 4~6 步，只看持仓
- 周末补录历史交易 → 只用 `/qk-stock-swing-trade`，日期写实际成交日

### 买入一只新票的完整链路

```
/qk-stock-b1-daily            扫出候选
    ↓
/qk-stock-b1-review 300314    体检：买点质量、止损位在哪
    ↓
/qk-stock-distribution 300314 排除：有没有出货嫌疑
    ↓
（人工决定买不买、买多少）
    ↓
/qk-stock-swing-trade         记一笔，必写止损计划 + 买入理由
    ↓
/qk-stock-swing-review 300314 复盘：买点质量 + 实际买价偏离多少
    ↓
（此后每日）/qk-stock-swing-daily
```

### 卖出与复盘

```
/qk-stock-swing-daily         日报提示止损触及 / 离场信号
    ↓
/qk-stock-swing-trade sell    卖出 + 记卖出理由
    ↓  清仓时自动归档 portfolio/swing/closed/<code>.md
/qk-stock-swing-trade verify  给当初的买入理由便签盖章（应验/证伪）
```

**清仓是最好的复盘时机** —— 一轮走完，当初写的判断能对照全程走势验证。

### 便签到期回看

`/qk-stock-swing-daily` 会在日报末尾列出到期待验证的便签。回看后用 `verify` 盖章，写清应验或证伪的**具体依据**，不要只写「对了」「错了」。

## 六、这套工具当前给不出什么

日报和分析里**不要假装有**这些：

- **仓位与择时层**：活跃市值定仓位、大盘守恒状态 —— 需要账户资金，见 [swing/TODO.md](swing/TODO.md)
- **盘中分时信号**：「10 点前快速拉升」「次日低开 2%」依赖分时数据，日线看不到
- **基本面与消息面**：减持、解禁、业绩预告、板块环境，一概不在视野内
- **手续费**：不存不算（决策 D15），盈亏是毛额
- **0AMV**：至今没有任何录入，没数据就跳过并标注
