# B1 买点评价

对单只个股做 B1 买点体检：脚本负责客观测量，你负责按规则做定性综合评价。

## 运行环境

必须切到 conda `stock` 环境（否则 akshare/pandas 等依赖 ImportError）：

```bash
cd /Users/qianqian/stock/AshareLab
conda run --live-stream -n stock python .claude/skills/qk-stock-b1-review/scripts/b1_review.py <股票名或代码> [日期]
```

脚本已自行处理 `sys.path`，无需 `PYTHONPATH=.`。`--live-stream` 必需，否则 `conda run` 会缓冲输出到进程结束。

```bash
# 名称输入（模糊匹配）+ 指定日期
... b1_review.py 宁波韵升 20250806
# 代码输入 + 默认最近交易日
... b1_review.py 600366
# 机器可读
... b1_review.py 600366 --json
```

数据来自本地 `database/ashare_data.db`（前复权日线）。若报数据不足或日期过旧，先跑 `/qk-stock-daily-update` 更新行情。

## 工作流

1. 跑脚本拿测量值。
2. 读 `references/b1_rules.md` —— 完整规则、四类图形差异、十个范本案例的实测标定表。**必读**，评价的基准全在里面，尤其是「优秀 vs 勉强」的量化参照。
3. 按下面的评价体系输出定性结论。

## 评价体系

### 第一步：硬门槛（Tier 1）

脚本的「硬门槛」段任一项 ✗ → 直接判定**不是 B1 买点**，说明差在哪、需要什么条件才成立，不要继续打分。

例外：白线>黄线不通过但差距极小（白黄比 0.99~1.00）且其他维度优秀 → 可提「接近成立，等一两天白线上穿」。

### 第二步：形态链条（Tier 2，权重最高）

这一层决定「是不是真的 B1」。逐项对照：

| 维度 | 看脚本字段 | 优秀 | 勉强 |
|---|---|---|---|
| 有点火 | `点火.找到` | True | False → 缺前提，直接否 |
| 顶部无量 | `量能.点火后最大量/点火最大量` | ≤0.8 | 0.8~1.3 |
| 缩量程度 | `量能.末日量/点火均量` | ≤0.33（缩至启动期 1/3 以下） | 0.33~0.60 |
| 地量 | `量能.末日量在近60日分位` | ≤0.15 | 0.15~0.35 |
| 黄线支撑 | `均线结构` | 未跌破，或跌破已收回 | 跌破未收回 → 减分 |

「跌破黄线后快速收回」是**强**支撑信号，比从未跌破更积极，别当成瑕疵。

### 第三步：图形归类

按 `位置背景` 和 `洗盘形态` 判断属于哪一类（细节见 references）：

- **完美一**：J≤13 + 极致缩量 + 区间位置 ≤0.5 + 回调形态规整
- **完美二**：缩量非极致、或 J 在 13~16、或靠长期横盘时间换空间
- **完美三**：点火后进入窄幅箱体横盘 + 红肥绿瘦明显（`红肥绿瘦_实体比` 高）
- **完美四**：`位置背景.是否高位=True` 或 `区间位置` 接近高位而仍缩量 → 缩量上涨型

脚本的 `策略判定.variant` 是 `hunt_b1` 的机器归类，可作参考但**以你的形态判断为准** —— 它只有三个分支且优先匹配完美一。

### 第四步：情境修正

- 前期涨幅低 → 洗盘浅是正常的，不要因为「回调不充分」减分（浮盈少的票可能只横盘 4 天）
- 前期涨幅高 → 洗盘时间应更长，横盘久是好事不是坏事
- 高位票 → 走完美四逻辑，风险更高、仓位要压缩

### 第五步：输出

写成一段有判断的话，不是字段罗列。必须包含：

1. **一句话结论** —— 是不是优秀的 B1，属于哪一类。别用「可能」「建议关注」这种没信息量的措辞
2. **最强的证据** 和 **最弱的环节**，各带具体数字
3. **止损方案** —— 用脚本 `止损` 段（贴黄线用黄线、离黄线远用白线），带上距现价百分比。若是完美四，明确提仓位要压缩
4. **需要人工确认的部分** —— 你只看了价量数据，基本面、消息面、板块环境都不在视野内

评级用词建议：`优秀范本` / `合格可试错` / `勉强、需等待` / `不构成 B1`。

## 判断纪律

- **量能优先于绝对指标。** J 值不达标但量能反转明确 → 仍可能成立（J=13.73 的野马电池就是范本案例）。反过来，J 值再漂亮，量能没缩下来就不是 B1。
- **J 值不是质量指标。** 十个范本案例 J 从 -13.42 到 13.73，与后续涨幅无关。它只是入场过滤。
- **图形类型不预示收益。** 涨幅最大的三个范本（111%/89%/80%）分属完美三/二/一。
- **`hunt_b1` 未命中不等于没价值。** 它是硬筛，为全市场扫描服务；单股评价要看各维度测量值。
- **不做收益预测。** 范本涨幅是事后描述，不构成统计证据。可以说形态强弱，不要说「预计涨 X%」。
- 数据只到评估日，不要用之后的走势验证判断（除非用户明确要求复盘）。

## 常见场景

**场景 1：评价当天的票**
```
用户: 看看海康威视现在算不算好的 B1
```
→ `b1_review.py 002415` → 按体系输出评价

**场景 2：复盘历史买点**
```
用户: 宁波韵升 2025-08-06 那个 B1 好在哪
```
→ `b1_review.py 宁波韵升 20250806` → 对照 references 里该案例的标定值讲

**场景 3：批量筛完再细看**
```
用户: hunt_both 选出这几只，逐个看下 B1 质量
```
→ 对每只跑脚本，按「优秀/合格/勉强」分组，先讲最好的两三只

**场景 4：脚本报数据不足**
→ 提示跑 `/qk-stock-daily-update` 更新行情；若是新股（K 线 <120 根）说明无法评估
